# 热点局域网离线通信方案

## 目标

三台安卓手机无需互联网、无需云服务器、无需 Google Play 服务，在房主开启的个人热点内完成整局斗地主。

## 拓扑

- 房主手机：开启个人热点，同时运行 TCP 游戏服务器和 UDP 房间发现服务。
- 两台加入手机：连接房主热点，通过 UDP 自动发现或手动 IP 连接 TCP 服务。
- 房主是唯一权威状态源，客户端只能提交操作，不能直接修改牌局。

## 端口

- UDP `39172`：房间发现。
- TCP `39173`：牌局长连接。

## 数据安全边界

- 服务端保存完整牌局。
- 每名玩家只收到自己的手牌；其他玩家只显示剩余张数。
- 所有操作携带状态版本号，旧版本或重复操作会被拒绝。
- 不访问 DNS，不配置公网域名，不上传日志或牌局。

## 连接流程

1. 客户端广播 `DDZ_DISCOVER_V1`。
2. 房主返回房间码、房间名称和 TCP 端口。
3. 客户端连接房主数据包来源地址，并发送加入请求。
4. 服务端分配玩家 ID 和恢复令牌。
5. 三名玩家准备后，房主开始发牌并发送各自视图。

## 失败后备

- 自动发现失败时，输入房主界面显示的局域网 IP、端口和房间码。
- 客户端断线后使用恢复令牌重连，服务端在短时间内保留座位。
- 房主退出或热点关闭时，本局结束；首版不做房主迁移。

## 完全离线清单

- 扑克牌、字体和音效全部随 APK 打包。
- 二维码在本地生成，不调用在线二维码网站。
- 无登录、广告、分析 SDK、远程配置和在线版本检查。
- `INTERNET` 权限仅用于安卓本地 TCP/UDP 套接字。
