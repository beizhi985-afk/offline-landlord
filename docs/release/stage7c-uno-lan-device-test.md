# Stage7C：UNO 局域网真机验收清单

> 本文件仅是 Stage7C 的待执行清单。Stage7B 不宣称真实 Android 多机验收通过。

## 测试环境

- 设备：2～4 台 Android 手机
- 网络：同一手机热点，记录热点设备 IP
- APK：确认所有设备安装同一版本、同一 `applicationId`
- 记录：设备型号、Android 版本、APK SHA-256、测试日期

## 房间与发现

- [ ] UNO 首页可进入局域网模式
- [ ] 房主创建 2/3/4 人房间
- [ ] 附近发现只显示 UNO V5 房间
- [ ] 手动输入 IP、端口、六位房间码可加入
- [ ] 错误房间码、错误 IP、游戏已开始时有可理解的错误提示

## Lobby

- [ ] 房主与远程玩家均能看到房间码和座位
- [ ] READY / UNREADY 同步
- [ ] 房主可添加、移除机器人
- [ ] 仅房主可以开始游戏
- [ ] 房间退出后服务端停止，远程端收到房间结束状态

## 牌局

- [ ] 2 真人 Quick 完整结束
- [ ] 真人 + 机器人 Quick 完整结束
- [ ] 4 座位混合真人/机器人 Quick 完整结束
- [ ] 出牌、摸牌、AFTER_DRAW、Wild 选色、UNO、Catch UNO 同步
- [ ] 远程玩家只看到自己的完整手牌和其他玩家的 handCount
- [ ] 回合、方向、revision、分数和结算同步
- [ ] Points 模式可进入下一局并累计分数
- [ ] MatchFinished 后显示最终结果

## 断线与退出

- [ ] 远程玩家断线后显示 RECONNECTING
- [ ] 合法 resume token 可恢复原 playerId、seat 和手牌
- [ ] 错误 token 显示可理解错误，不能生成新座位
- [ ] 新连接替换旧连接后，旧连接不能继续发送 ACTION
- [ ] 房主退出时不发生 host migration，远程端显示 HOST_CLOSED
- [ ] 远程玩家退出时房主保留座位并按既有接管规则继续

## 视觉验收

- [ ] 横屏小屏设备上首页、Lobby、牌桌无裁切或重叠
- [ ] 手牌可读、可操作，中央牌堆不遮挡按钮
- [ ] 当前玩家、方向、Wild 弹窗和结算信息清楚
