- [ ] V3.7可以覆盖安装V3.6，原应用ID保持不变。

- [ ] 手机B和手机C均连接手机A创建的热点。
- [ ] 三台手机均允许应用使用局域网和网络相关权限。

## 测试流程

1. 手机A打开《离线斗地主》，创建斗地主房间。
2. 记录手机A显示的房主IP、端口和六位房间码。
3. 手机B、手机C点击“寻找附近房间”。
4. 手机B、手机C选择手机A创建的房间；如果没有自动发现，则手动填写房主IP、端口和六位房间码。
5. 确认三台手机都显示同一个房间、相同房间码和三名玩家。
6. 三名玩家分别点击“准备好啦”。
7. 确认牌局开始，并依次完成叫地主和加倍流程。
8. 按正常规则完成至少一局完整牌局。
9. 核对三台手机上的胜负、倍数、单局分数和累计积分。
10. 在第二局牌局中执行断线、机器人接管和重连测试。

## 逐项验证

### 房间与连接

- [ ] 手机A成功创建房间并显示六位房间码。
- [ ] 手机B、手机C能够通过UDP发现附近房间。
- [ ] 手机B、手机C能够通过六位房间码加入。
- [ ] 三台手机进入房间后玩家昵称、座位、局数和加倍设置一致。
- [ ] 三人点击准备后正常开始，不出现“发送失败”。

### 完整牌局

- [ ] 三台手机手牌彼此独立，其他玩家只能看到剩余张数。
- [ ] 叫地主顺序和结果在三台手机上同步。
- [ ] 加倍选择、倍数和地主身份在三台手机上同步。
- [ ] 当前操作玩家和地主/农民身份提示在三台手机上同步。
- [ ] 每次出牌后，三台手机显示相同的桌面牌和剩余牌数。
- [ ] 不出和回合切换结果在三台手机上同步。
- [ ] 一局结束后，胜负、最终倍数和三人分数变化一致。
- [ ] 下一局开始后，累计积分和局数进度一致。

### 断线、重连与接管

1. 在轮到手机B或手机C操作前，暂时断开该手机的热点连接。
2. 等待房主端触发机器人接管。
3. 确认牌局可以继续，机器人能够完成该座位的合法操作。
4. 让断线手机重新连接同一热点并返回应用。
5. 确认该手机恢复原座位、原手牌和原积分，并重新取得控制权。

- [ ] 断线后房主和另一加入端没有卡死或崩溃。
- [ ] 机器人接管后牌局能够继续。
- [ ] 重连后恢复的是原座位，而不是创建新玩家。
- [ ] 重连后手牌、身份、积分和当前牌局状态一致。
- [ ] 牌局中央不显示“断线/重新连接”事件，只显示当前操作玩家。
