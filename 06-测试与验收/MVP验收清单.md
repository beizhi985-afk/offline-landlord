# MVP 验收清单

## 规则

- [ ] 54 张牌无重复、无遗漏。
- [ ] 标准牌型均能正确识别，非法组合被拒绝。
- [ ] 炸弹和王炸比较正确。
- [ ] 两次不出后由上一手玩家重新领出。
- [ ] 地主、农民胜负和春天结算正确。

## 三机通信

- [ ] 三台手机关闭移动数据后仍可完成一整局。
- [ ] 房主开启热点后，另外两台能自动发现房间。
- [ ] 自动发现失败时可通过 IP 加入。
- [ ] 每台手机只能看到自己的手牌。
- [ ] 客户端短暂断开 Wi-Fi 后可恢复座位和牌局状态。

## 隧道场景

- [ ] 开局后开启飞行模式，再单独打开 Wi-Fi 和热点，牌局可继续。
- [ ] 无 SIM 卡或无运营商信号时可以创建和加入房间。
- [ ] 应用运行期间没有任何公网请求。
