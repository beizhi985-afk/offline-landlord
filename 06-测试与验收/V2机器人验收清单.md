# V2 机器人验收清单

## 自动测试

- [x] 合法出牌生成器只产生规则引擎认可的牌型。
- [x] 接牌候选全部能够压过上一手。
- [x] 只有房主可以添加或移除机器人。
- [x] 机器人加入后自动准备。
- [x] 断线玩家可以进入托管状态。
- [x] 玩家重连后自动取消断线托管。
- [x] 2000 局自动对战均能正常结束，无非法操作和死局。

## 单机真机

- [ ] 一名真人添加两个机器人后能够开始游戏。
- [ ] 机器人叫分、出牌和不出的动画节奏可接受。
- [ ] 真人主动托管后机器人能接着完成当前回合。
- [ ] 取消托管后真人能够在下一次轮到时操作。
- [ ] V1 与 V2 可以同时安装和启动。

## 多机与断线

- [ ] 两名真人加一个机器人可通过热点完成整局。
- [ ] 客户端断开 Wi-Fi 8 秒后机器人开始代打。
- [ ] 客户端重新连接后座位、手牌和分数保持不变。
- [ ] 重连后机器人停止代打，控制权交还真人。
- [ ] 无公网信号和隧道环境中机器人功能不受影响。
