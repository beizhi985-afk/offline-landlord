# V3.4 手牌滑动多选验收清单

## 自动化验收

- [x] 单击未选牌后仅选中该牌。
- [x] 再次单击已选牌后仅取消该牌。
- [x] 从左向右和从右向左均能生成连续选择区间。
- [x] 从未选牌开始固定为批量选择模式。
- [x] 从已选牌开始固定为批量取消模式。
- [x] 滑到远处再反向滑回时，预览范围按起点和当前位置缩小。
- [x] 滑出左右边界时索引钳制在第一张或最后一张牌。
- [x] 同点数、不同花色的牌按唯一 `card.id` 独立选择。
- [x] 未超过阈值时仍按点击处理，超过阈值后只提交滑动结果。
- [x] 取消手势后清空预览且不修改正式选牌。
- [x] 滑动结果通过现有 `selectedIds` 传给原有出牌入口。
- [x] 全部 39 项 JVM 测试通过，debug APK 构建成功。

## Android 真机验收（安装后人工确认）

- [ ] 用手指从 4 滑到 8，途中 4～8 实时抬起并显示薄荷色描边。
- [ ] 不松手滑回 6，临时范围应缩小为 4～6。
- [ ] 松手后只有 4～6 正式选中。
- [ ] 从已选中的 4 再滑到 6，松手后 4～6 全部取消。
- [ ] 反向从右向左滑动效果相同。
- [ ] 横向滑动时牌桌不滚动、不闪跳、不遗漏重叠牌。
- [ ] 松手后不会额外切换某一张牌。
- [ ] “出牌”和“不出”后不残留临时高亮。

> 本清单中的真机项必须在实际 Android 手机上用手指确认；JVM 测试和编译成功不能替代触感与阈值验收。
