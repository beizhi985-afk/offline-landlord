# V3 界面验收清单

## 必验画面

- [x] 启动大厅：品牌、创建房间和加入房间区域完整可见。
- [x] 等待房间：三个座位、机器人增删、准备按钮、房间码和热点地址完整可见。
- [x] 叫分阶段：左右对手、三张底牌、叫分按钮和自己手牌无遮挡。
- [x] 出牌阶段：选牌上浮、出牌/不出按钮、上一手牌和剩余牌数清晰可辨。
- [x] 结算阶段：胜负文案、倍数和下一局按钮完整可见。

## 视觉标准

- [x] 854×480 横屏下无文字裁切、控件重叠或内容越界。
- [x] 纸牌点数和花色一眼可辨，20 张手牌仍能完整放入底部区域。
- [x] 当前回合玩家有明显暖黄色高亮。
- [x] 红黑牌、选中牌、禁用按钮和托管状态有明确差异。
- [x] 大厅、等待房间和牌桌使用统一的清新配色与圆角语言。
- [x] 截图中不出现乱码、联网提示、远程图片占位或第三方品牌素材。
- [x] 牌桌不显示中央椭圆背景，对手头像缩小且不使用白色大底板。
- [x] 所有页面均不展示浪漫或治愈短语。
- [x] 三张地主底牌固定在顶部中央，大小王以红黑竖排 `JOKER` 显示。
- [x] 左、右、下方玩家的上一手牌分别靠近对应玩家显示。
- [x] “不出”和“出牌”上移并降低透明度，不遮死手牌和玩家出牌。
- [x] 轮不到自己或领出未选牌时不显示无用按钮；跟牌未选时只显示“不出”，选牌后才显示“出牌”。
- [x] 12 局、24 局和是否加倍三个模式选项均无文字裁切。
- [x] 加倍阶段的“不加倍”和“加倍”按钮完整显示，并只在当前玩家需要选择时出现。

## 功能回归

- [x] 创建房间、自动发现和手动加入入口仍可操作。
- [x] 添加/移除机器人与准备流程仍可操作。
- [x] 叫分、选牌、出牌、不出和托管仍可操作。
- [x] 12 局模式可开始并正确显示“第1/12局”。
- [x] 24 局模式可开始并正确显示“第1/24局”。
- [x] 开启加倍时三名玩家依次选择并更新倍数；关闭加倍时叫分后直接进入出牌。
- [x] 20 项单元测试全部通过，另完成 2000 局机器人自动对战压力测试。
