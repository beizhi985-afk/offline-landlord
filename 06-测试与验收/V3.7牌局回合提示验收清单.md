# V3.7 牌局回合提示验收清单

## 自动验收

- [x] 叫地主阶段显示“轮到玩家名叫地主”。
- [x] 加倍阶段显示“轮到玩家名选择是否加倍”。
- [x] 出牌阶段显示“轮到玩家名（地主/农民）出牌”。
- [x] 牌局中玩家断线或重连不会覆盖当前回合提示。

## 三机真机验收

- [ ] 三台手机均覆盖安装V3.7并进入同一房间。
- [ ] 叫地主、加倍和出牌轮次在三台手机上显示一致。
- [ ] 任意加入手机暂时断开热点，另外两台手机中央不出现断线文字。
- [ ] 该手机重新连接后，三台手机中央不出现重新连接文字。
- [ ] 断线托管仍正常生效，且中央始终显示当前应该操作的玩家。
