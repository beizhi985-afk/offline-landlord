# 离线斗地主

三台安卓手机在没有互联网的情况下进行经典三人斗地主。三台手机安装同一个 APK，其中一台创建房间并充当局域网游戏服务器，另外两台通过房主热点加入。

## 当前里程碑

`v0.1.0` 目标是完成可在三台真机上试玩的 MVP：

- 经典三人斗地主规则与牌型校验
- 一台手机创建房间，另外两台通过热点局域网加入
- 自动发现、手动 IP 加入和六位房间码
- 叫分、出牌、不出、炸弹倍数、春天和结算
- TCP 长连接、状态版本和基础重连
- 横屏 Compose 牌桌

当前源码已通过规则与通信单元测试，并生成可安装的 `v0.1.0-debug` APK。下一步是三台安卓真机在热点环境下完成整局、断线重连和隧道场景验收。

## 可安装版本

安装包位于：

```text
07-构建与交付/离线斗地主-v0.1.0-debug.apk
```

三台手机必须安装同一个 APK。调试版仅用于自己和朋友侧载试玩，不需要应用市场。

## 开发构建

本机已经配置项目专用 JDK 17、Android SDK 37 和 Gradle Wrapper。推荐使用仓库自带脚本，它会先测试再打包，并处理 Windows 中文路径兼容问题：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\07-构建与交付\本地构建.ps1
```

调试 APK 输出到：

```text
android-app/build/outputs/apk/debug/android-app-debug.apk
```

## 离线保证

应用没有登录、广告、分析 SDK、在线字体、远程图片、云数据库或在线版本检查。清单里的 `INTERNET` 权限仅用于安卓本地 TCP/UDP 套接字。
