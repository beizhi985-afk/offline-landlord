# 离线斗地主

安卓手机在没有互联网的情况下进行经典三人斗地主。V3 支持一至三名真人，其余座位可由房主手机上的离线机器人补齐；真人仍可通过房主热点加入，并提供全新的清新横屏牌桌。

## 当前里程碑

阶段6已经让UNO单机模式在APP内完整可玩：

- UNO 首页、单机配置页与横屏牌桌使用独立的湖畔露台背景图；斗地主继续保留原有风景背景。该 UNO 资源将供后续页面复用。
- 游戏选择中的UNO进入独立首页，可选择单机游戏；局域网入口继续显示“敬请期待”，不会创建房间或网络会话。
- 单机配置支持2、3、4名总玩家，固定1名真人“你”和1～3名NORMAL机器人；支持Quick一局决胜和500分Points积分赛。
- 横屏Compose牌桌提供UNO专用牌面、合法牌明暗提示、摸牌、AFTER_DRAW、不出、Wild选色、手动喊UNO、抓UNO、当前玩家、方向和当前有效颜色。
- `UnoSinglePlayerController`串行提交真人和Bot动作，Compose不持有或修改Engine；Bot延迟可注入且同一状态只启动一条动作链，快速连点不会重复提交。
- 真人只看到自己的完整手牌；机器人只显示背面牌和剩余数量，公平信息边界与阶段5一致。
- Quick结束可再来一局；Points每局显示得分和累计排行榜，未达到500分时通过Engine开始下一局，整场结束可再来一场。
- 阶段6新增36项JVM测试，连同原226项共262/262通过；Controller Quick 1000/1000局和Points 100/100场通过，全部旧压力测试继续通过。
- Android Debug构建成功；UNO局域网、UNO房间和UNO V5 adapter仍未实现，阶段7才开发局域网联机。

阶段3在阶段2公共 LAN transport 之上建立 V5 多游戏网络协议：

- 应用打开后先进入“离线牌局”游戏选择页。
- 斗地主入口复用V3.7原有首页、房间、牌桌、规则和联机流程。
- UNO当前仍显示“开发中”占位页；纯Kotlin规则核心已经存在，但尚未接入UI、机器人、房间或网络。
- `shared/GameType` 提供 `LANDLORD` / `UNO`，供应用壳与 V5 通用协议共同使用，不依赖 UI 或斗地主 core。
- 新版斗地主客户端默认使用 V5；斗地主房主同时接受 V4 / V5，并按连接版本分别发送状态。
- V5 通用信封包含 `gameType` 与泛型 `payload`，斗地主的 `PlayerAction` / `PlayerGameView` 位于独立 Landlord V5 adapter 中。
- UDP 同时支持 V5 JSON 广告 `OFFLINE_GAMES_DISCOVER_V5` 和历史 V4 斗地主广告；同一房间去重时优先 V5，V4-only 房间仍可加入。
- V4 JSON、`DDZ_DISCOVER_V4` 和 `DDZ_HOST_V4` 历史格式继续保留并有 golden 测试保护。
- 阶段3基线的93项测试继续保留；阶段4加入UNO核心测试后共185/185项通过。本机真实 TCP 回环兼容测试仍通过，斗地主机器人压力测试完成2000/2000局。
- UNO仍只有“开发中”入口；核心规则尚未连接房间或网络会话，也未引入第三方网络库。
- `applicationId`仍为`com.offlinelandlord.game.v2`，应用版本仍为`0.3.7`；V5是新的多游戏网络协议。

## 版本独立

- V1 原版：Git 标签 `v0.1.0`，应用 ID `com.offlinelandlord.game`
- V2 机器人版：Git 标签 `v0.2.0`，应用 ID `com.offlinelandlord.game.v2`
- V3 清新界面版：沿用应用 ID `com.offlinelandlord.game.v2`，可覆盖升级 V2

两个版本可以同时安装在同一台手机上，代码快照和 APK 互不覆盖。

从 V2 之后采用普通覆盖升级方式，不再更换应用 ID或复制独立工程；每版递增版本号、更新 [`CHANGELOG.md`](CHANGELOG.md) 并创建 Git 标签。

## 开发构建

本机已经配置项目专用 JDK 17、Android SDK 37 和 Gradle Wrapper。推荐使用仓库自带脚本，它会先测试再打包，并处理 Windows 中文路径兼容问题：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\07-构建与交付\本地构建.ps1
```

调试 APK 输出到：

```text
android-app/build/outputs/apk/debug/android-app-debug.apk
```

## 离线保证

应用没有登录、广告、分析 SDK、在线字体、远程图片、云数据库或在线版本检查。清单里的 `INTERNET` 权限仅用于安卓本地 TCP/UDP 套接字。
## Stage 7A UNO LAN core

The `feat/uno-lan-v5-core` branch adds the first UNO V5 LAN authority without opening a UI entry. Existing transport and generic V5 envelopes remain unchanged. `UnoHostSession` is the only authority and feeds the existing `UnoEngine`/`UnoBot`; player-specific projections keep opponent cards private. Host migration is intentionally out of scope.
