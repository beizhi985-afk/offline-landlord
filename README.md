# 离线斗地主

安卓手机在没有互联网的情况下进行经典三人斗地主。V3 支持一至三名真人，其余座位可由房主手机上的离线机器人补齐；真人仍可通过房主热点加入，并提供全新的清新横屏牌桌。

## 当前里程碑

阶段1在 `v3.7-baseline` 之上建立多游戏应用壳：

- 应用打开后先进入“离线牌局”游戏选择页。
- 斗地主入口复用V3.7原有首页、房间、牌桌、规则和联机流程。
- UNO当前仅提供“开发中”占位页，不包含牌组、规则、机器人、房间或网络实现。
- 斗地主ViewModel延迟到进入斗地主后创建；其原有TCP/UDP生命周期没有改动。
- 应用显示名称改为“离线牌局”，`applicationId`仍为`com.offlinelandlord.game.v2`，网络协议仍为V4。
- 原斗地主44项回归测试和阶段1新增5项测试全部通过，共49/49项；Android debug构建成功。
- 下一阶段为阶段2：公共房间与网络边界梳理，本阶段尚未开始该抽离。

`v0.3.7` 是牌局回合提示优化版：

- 牌局进行中不再用断线、重连或托管事件覆盖中央提示。
- 叫地主、加倍和出牌阶段始终显示当前应该操作的玩家。
- 出牌阶段同时标明当前玩家属于地主方还是农民方。
- V3.7 已获项目负责人批准冻结为 `v3.7-baseline` 开发基线；44/44 项自动测试通过，Android APK 构建成功。
- 本次冻结未重新完成完整三台真机验收。项目负责人已知并接受该剩余风险，三机验收记录仍保持“待验收”。

`v0.3.6` 是联机动作发送修复版：

- 修复加入玩家点击准备、叫分、加倍、出牌或不出时因主线程网络I/O导致发送失败的问题。
- 客户端动作统一切换到 `Dispatchers.IO`，界面层通过协程异步发送。
- 新增真实TCP“加入房间→发送准备→房主应用准备状态”回归测试。

`v0.3.5` 修复了局域网连接端口：

- 修复客户端因 Kotlin 接收者属性遮蔽而始终连接到 0 端口的问题。
- 增加真实 TCP 客户端连接服务端测试，并在连接前拒绝无效端口。
- 手动加入时 IP 输入框不再预填示例地址，并明确提示 IP 不包含端口。
- 连接超时、拒绝和 IP 格式错误改为中文提示。

`v0.3.4` 增加了滑动多选：

- 保留单张点击选牌，并新增重叠手牌区域的横向滑动多选。
- 支持从左向右、从右向左选择，滑回时选择范围会实时缩小。
- 从未选中的牌开始为批量选择，从已选中的牌开始为批量取消。
- 滑动时只显示临时预览，松手后才提交到现有出牌逻辑。

`v0.3.3` 增加了更新提示与整场战绩：

- 经典三人斗地主规则与牌型校验
- 一台手机创建房间，另外两台通过热点局域网加入
- 自动发现、手动 IP 加入和六位房间码
- 叫分、出牌、不出、炸弹倍数、春天和结算
- 创建房间时选择 12 局或 24 局，并在牌桌显示局数进度
- 可选择开启或关闭三人依次加倍
- 出牌操作按钮按需显示，并与手牌保持清晰间距
- 新版本首次启动显示完全离线的更新说明
- 每次发牌随机决定第一位叫地主的玩家
- 12/24 局结束后生成最终排行榜和逐局分数记录
- TCP 长连接、状态版本和基础重连
- 清新 INS 风横屏 Compose 牌桌和原创圆角纸牌
- 原创手绘半写实湖畔背景，完全随 APK 离线加载
- 房主添加或移除机器人补齐空位
- 玩家主动托管和取消托管
- 玩家断线 8 秒后自动代打，重连后立即取回控制权
- 机器人只读取自己的手牌和公开牌局信息，不读取其他玩家手牌
- 合法出牌生成器覆盖单牌、对子、顺子、连对、飞机、四带二、炸弹和王炸
- 已通过 2000 局机器人自动对战压力测试

当前源码已通过规则、通信、机器人、自动对局与界面构建测试。下一步仍建议完成三台安卓真机上的热点、托管、断线接管和隧道场景验收。

## 版本独立

- V1 原版：Git 标签 `v0.1.0`，应用 ID `com.offlinelandlord.game`
- V2 机器人版：Git 标签 `v0.2.0`，应用 ID `com.offlinelandlord.game.v2`
- V3 清新界面版：沿用应用 ID `com.offlinelandlord.game.v2`，可覆盖升级 V2

两个版本可以同时安装在同一台手机上，代码快照和 APK 互不覆盖。

从 V2 之后采用普通覆盖升级方式，不再更换应用 ID或复制独立工程；每版递增版本号、更新 [`CHANGELOG.md`](CHANGELOG.md) 并创建 Git 标签。

## 可安装版本

安装包位于：

```text
07-构建与交付/离线斗地主-v0.3.7-ui-debug.apk
```

参加同一房间的手机必须安装同一个 V3 APK。调试版仅用于自己和朋友侧载试玩，不需要应用市场。

## 开发构建

本机已经配置项目专用 JDK 17、Android SDK 37 和 Gradle Wrapper。推荐使用仓库自带脚本，它会先测试再打包，并处理 Windows 中文路径兼容问题：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\07-构建与交付\本地构建.ps1
```

调试 APK 输出到：

```text
android-app/build/outputs/apk/debug/android-app-debug.apk
```

## 离线保证

应用没有登录、广告、分析 SDK、在线字体、远程图片、云数据库或在线版本检查。清单里的 `INTERNET` 权限仅用于安卓本地 TCP/UDP 套接字。
