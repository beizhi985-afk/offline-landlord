# 离线斗地主

安卓手机在没有互联网的情况下进行经典三人斗地主。V2 支持一至三名真人，其余座位可由房主手机上的离线机器人补齐；真人仍可通过房主热点加入。

## 当前里程碑

`v0.2.0` 是独立机器人版本：

- 经典三人斗地主规则与牌型校验
- 一台手机创建房间，另外两台通过热点局域网加入
- 自动发现、手动 IP 加入和六位房间码
- 叫分、出牌、不出、炸弹倍数、春天和结算
- TCP 长连接、状态版本和基础重连
- 横屏 Compose 牌桌
- 房主添加或移除机器人补齐空位
- 玩家主动托管和取消托管
- 玩家断线 8 秒后自动代打，重连后立即取回控制权
- 机器人只读取自己的手牌和公开牌局信息，不读取其他玩家手牌
- 合法出牌生成器覆盖单牌、对子、顺子、连对、飞机、四带二、炸弹和王炸
- 已通过 2000 局机器人自动对战压力测试

当前源码已通过规则、通信、机器人和自动对局测试。下一步是安卓真机上的热点、托管、断线接管和隧道场景验收。

## 版本独立

- V1 原版：Git 标签 `v0.1.0`，应用 ID `com.offlinelandlord.game`
- V2 机器人版：Git 分支 `v0.2.0-bot`，应用 ID `com.offlinelandlord.game.v2`

两个版本可以同时安装在同一台手机上，代码快照和 APK 互不覆盖。

从 V2 之后采用普通覆盖升级方式，不再更换应用 ID或复制独立工程；每版递增版本号、更新 [`CHANGELOG.md`](CHANGELOG.md) 并创建 Git 标签。

## 可安装版本

安装包位于：

```text
07-构建与交付/离线斗地主-v0.2.0-bot-debug.apk
```

参加同一房间的手机必须安装同一个 V2 APK。调试版仅用于自己和朋友侧载试玩，不需要应用市场。

## 开发构建

本机已经配置项目专用 JDK 17、Android SDK 37 和 Gradle Wrapper。推荐使用仓库自带脚本，它会先测试再打包，并处理 Windows 中文路径兼容问题：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\07-构建与交付\本地构建.ps1
```

调试 APK 输出到：

```text
android-app/build/outputs/apk/debug/android-app-debug.apk
```

## 离线保证

应用没有登录、广告、分析 SDK、在线字体、远程图片、云数据库或在线版本检查。清单里的 `INTERNET` 权限仅用于安卓本地 TCP/UDP 套接字。
