# 本地构建与安装

## 直接安装

已经构建好的安装包位于：

```text
07-构建与交付/离线斗地主-v0.2.0-bot-debug.apk
```

将同一个 V2 APK 发给参加同一房间的安卓手机并安装即可，不需要应用市场或网络账号。V2 使用独立应用 ID，可以和 V1 同时安装。

## 构建

在 `07-构建与交付` 目录右键打开 PowerShell，然后运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\本地构建.ps1
```

脚本会先运行全部规则和通信测试，再生成 APK。它还会自动使用临时英文构建入口，避开部分 Windows 版本在中文路径下运行 Gradle 测试时的乱码问题；原仓库仍保留在当前中文目录。

## 安装

1. 将 `离线斗地主-v0.2.0-bot-debug.apk` 发送到参加游戏的安卓手机。
2. 在系统设置中允许当前文件管理器“安装未知应用”。
3. 所有真人玩家安装同一个 V2 APK。
4. 多人游戏时，一人开启个人热点，其他人连接该热点。
5. 房主创建房间，其他玩家自动发现或输入 IP 加入。
6. 人数不足时，房主在等待房间中点击“添加机器人”补齐三个座位。
7. 牌局中可点击“托管”；断线超过 8 秒也会自动由机器人代打。

调试版升级时可以直接覆盖安装；不要更改应用 ID 或签名，否则需要先卸载旧版本。
